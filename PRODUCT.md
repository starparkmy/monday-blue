# monday blue
## Platform
Mobile-first web app, usable from a phone browser without an app store. Existing email/password staff accounts remain.
## Job
Warehouse staff take pictures and save a return immediately. Details can be added later. The user requested a fresh start on 2026-11-17, with photo capture and a Trello-like template first.
## Confirmed workflow
Received-date lists (confirmed by user), photo covers, R-number per return, attachments, editable description, labels and comments. Daily numbers use UK midnight and a dated unique reference; N is a fixed suffix. Existing app and records must remain recoverable.
## Scope
First version is capture and record keeping. No automated OCR, refund or stock movement in this board. Protected server persistence requires a connection. Light blue branding retained from user instructions.
